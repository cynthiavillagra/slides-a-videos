📖 Guía rápida: ¿En qué formato deben estar los archivos que subas? (Clic para desplegar)
1. Diapositivas / Slides
  • PDF (.pdf): Un solo archivo; extrae página 1 a slide 1, etc.
  • PowerPoint (.pptx / .ppt): Extrae las diapositivas e imágenes.
  • Imágenes (.png, .jpg): Si son sueltas, nombrarlas con número (01_portada.png, 02_tema.png).
2. Guion Narrativo
  • Formatos: .docx, .doc, .pdf, .md o .txt (o escribirlo directo).
  • Estructura con tags: Usá [SLIDE 1], [SLIDE 2] y [CODIGO: ruta/archivo.py] para ordenar de arriba a abajo.
  • Si ponés párrafos bajo [CODIGO: ...], se usan como locución de ese fragmento de código.
3. Código / Proyecto
  • Carpeta entera o ZIP: Sube todo el proyecto para el explorador de VS Code.
  • Scripts (.py, .js, .html): Puede tener marcas # [PASO 1] o separarse por funciones.
  • Notebooks (.ipynb): Convierte celdas Markdown a voz y celdas Code a tipeo con outputs.
